# 企业本体总览 PRD

## 1. 文档信息

- 产品：OntoZ 工作台
- 功能：企业本体
- 版本：V1.0
- 状态：本轮实现
- 目标用户：企业管理员、外贸负责人、销售与营销团队成员

## 2. 背景与目标

OntoZ 的各智能体需要基于一致、可信的企业知识开展获客、触达、建站、投流和社媒运营。企业本体总览参考知识库产品的“知识健康度 + 核心资料 + 知识空间入口”结构，让用户快速回答三个问题：

1. OntoZ 目前有多理解我的企业？
2. 当前识别的企业基本信息是否正确？
3. 哪些业务知识已经沉淀，接下来可以去哪里查看和完善？

本期目标是完成企业本体一级总览页，不展开三个二级模块的内容。

## 3. 信息架构

企业本体总览由三个区块组成：

1. 企业本体得分
   - 0–100 分仪表盘
   - 当前理解等级
   - 一句话理解结论
   - 业务信息、产品知识、市场认知三项维度
2. 企业简介
   - 公司名称
   - 官网
   - 国家/地区
   - 成立年份
   - 公司类型
   - 员工人数
   - 公司简介
3. 本体功能模块
   - 买家搜索策略
   - 行业知识图谱
   - 企业知识库

## 4. 页面与路由

- 一级页：`#ontology`
- 买家搜索策略：`#ontology/buyer-search-strategy`
- 行业知识图谱：`#ontology/industry-knowledge-graph`
- 企业知识库：`#ontology/enterprise-knowledge-base`

买家搜索策略二级页已在后续迭代中完成，具体需求见 `buyer-search-strategy-prd.md`。行业知识图谱和企业知识库仍保留目标路由与功能说明，点击后提示“二级页面将在后续版本中补充”，避免进入无内容页面。

## 5. 页面需求

### 5.1 页面头部

- 标题：企业本体
- 说明：集中查看 OntoZ 对企业业务、产品与市场知识的理解
- 辅助状态：最近更新日期

### 5.2 企业本体得分

- 当前演示分数：82/100
- 等级：理解良好
- 一句话结论：已能较准确理解企业的核心业务、产品能力与目标市场，可支持智能体开展日常获客与营销工作。
- 分项：
  - 业务信息：92%
  - 产品知识：84%
  - 市场认知：70%
- 表现形式：环形仪表盘 + 文字结论 + 分项进度
- 分数语义：
  - 0–39：信息不足
  - 40–59：初步理解
  - 60–79：基本理解
  - 80–89：理解良好
  - 90–100：理解深入

### 5.3 企业简介

演示数据与现有 NOX Robotics 产品场景保持一致：

- 公司名称：NOX Robotics Ltd.
- 官网：noxrobotics.ai
- 国家/地区：新加坡
- 成立年份：2021
- 公司类型：私营企业
- 员工人数：201–500 人
- 公司简介：NOX Robotics 专注于面向制造、仓储与设施巡检场景的通用人形机器人及具身智能解决方案，通过开放集成能力帮助企业将感知、决策与执行接入真实业务流程。

### 5.4 功能模块

每张模块卡片包含图标、名称、内容规模、描述、最近更新时间和查看入口。

- 买家搜索策略

  - 统一管理产品手册、案例、FAQ、品牌资料与销售素材

## 6. 交互与状态

- 侧边栏“企业本体”点击后进入 `#ontology` 并保持选中态。
- 页面切换后，焦点落在页面一级标题，支持键盘用户确认导航结果。
- 三个模块入口支持键盘聚焦。
- 点击买家搜索策略进入对应图谱页，并保持侧边栏“企业本体”选中。
- 行业知识图谱和企业知识库未建设期间，点击入口显示轻提示，不改变当前路由。
- 官网使用新窗口打开，并提供可识别的外链提示。

## 7. 响应式要求

- 桌面端：得分卡左右分栏；企业字段六列信息栅格；模块三列展示。
- 平板端：得分卡改为单列；企业字段两列；模块可按空间换行。
- 手机端：所有区块单列；模块入口占满卡片宽度；文字不溢出。
- 验收视口：390px、768px、1440px。

## 8. 可访问性要求

- 仪表盘提供可读的 `aria-label`，不能只依赖颜色表达分数。
- 进度条使用 `role="progressbar"` 及对应数值属性。
- 页面区块使用明确标题层级。
- 所有图标均为装饰，交互名称由可见文字或 `aria-label` 提供。
- 焦点样式沿用产品全局规范。

## 9. 验收标准

- `#ontology` 可直接访问，刷新后页面仍正确显示。
- 侧边栏选中态、浏览器标题和移动端标题均显示“企业本体”。
- 得分、理解结论、七项企业简介字段和三个模块完整展示。
- 模块点击不会跳到错误页面，并出现后续补充提示。
- 页面在 390px、768px、1440px 下无横向溢出和内容遮挡。
- 浏览器控制台无 JavaScript 错误，图片、字体和图标正常加载。

## 10. 后续迭代

- 二级页支持搜索、筛选、详情浏览、资料引用关系和更新时间线。
- 支持企业简介的编辑、来源追溯与字段置信度。
- 支持得分规则动态计算、缺失项提示与“一键完善本体”。
- 支持智能体调用记录，展示哪些知识被 Zoe、Lily、Lucas、John、Wendy 使用。
