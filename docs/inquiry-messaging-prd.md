# 询盘消息 PRD

版本：1.0 · 2026-09-16

## 目标与当前范围

销售人员按渠道管理询盘，在指定 WhatsApp 账号下与客户或群组沟通。项目目前为静态前端演示，本次交付完整的本地交互；发送、建群只在当前页面会话内生效，刷新恢复示例数据。页面明确标注演示状态，不将本地操作描述为真实送达。

## 信息架构

1. 页面最顶部固定三个一级渠道：邮件、WhatsApp、WhatsApp 企业号，各显示该渠道所有账号的未读消息总数。移除列表内的「全部渠道」及 LinkedIn 入口，保留历史 LinkedIn 数据但不混入这三个渠道。
2. 渠道下显示账号栏。邮件显示发件邮箱；两个 WhatsApp 渠道支持独立账号切换，显示账号名称、号码、未读数量及演示连接状态。切换渠道记住该渠道上次使用的账号。
3. 账号下为会话列表、聊天区、资料区。会话、搜索、联系人、群组、草稿、附件均限定于当前账号。切换账号重置列表搜索/未读筛选，恢复该账号上次会话；没有会话时显示空态，不展示其他账号的消息。

## 功能要求

### 会话与文本

- 保留邮件主题、回复、附件、公司资料、AI 润色等原有能力。
- WhatsApp 两个渠道均支持单聊和群聊，列表可按客户、公司、号码、消息搜索，可筛选未读。
- 打开会话清除未读，实时更新账号和渠道角标。文本上限 3000 字；纯空白不可发送；有附件可单独发送。
- Ctrl/Cmd + Enter 发送，Enter 换行；中文输入法合成期间不触发快捷发送。
- 草稿与待发附件按会话保留，渠道/账号切换不串发；发送后更新会话摘要并置顶。

### 图片、视频、文件

- 两个 WhatsApp 渠道提供「图片/视频」「文件」两个独立入口；邮件保留文件附件。
- 选择后显示文件名、大小、缩略图或视频预览；可逐个移除；发送后图片可放大、视频可播放、文件可下载。
- 本地原型统一限制单文件 25 MB、每条消息最多 10 个附件（产品演示限制，不代表 WhatsApp 官方限制）。拒绝空文件、超限文件和媒体入口不支持的类型，并提供提示；其余合法文件仍可加入。
- 缺少实际内容的历史示例附件明确提示无文件可下载。移除待发文件释放临时资源。

### 查找联系人与新会话

- 两个 WhatsApp 渠道提供「查找联系人」入口，弹窗按姓名、公司、号码搜索当前账号的联系人。
- 点击联系人打开已有单聊，或创建当前账号的新单聊，不重复创建。没有匹配项时显示空态。

### 创建群组

- 两个 WhatsApp 渠道提供「创建群组」，填写群名（去除首尾空白，1–60 字）并选择至少 2 位当前账号联系人。
- 成员列表可搜索、多选，显示已选人数；未满足条件时不可创建。取消不产生群组。
- 成功后在当前账号创建并打开群聊，展示群名、成员人数、成员资料；可发送文本、图片、视频和文件。
- 不包含语音通话、视频通话及相关按钮；本次不包含群成员管理、撤回、转发或真实账号绑定。

## 交互与适配

- 桌面端三栏，平板端会话列表 + 聊天，资料按需展开；手机端在会话列表、聊天、资料之间逐级返回。
- 渠道导航始终位于询盘页顶部，窄屏可横向滚动；账号栏和操作按钮自适应换行，无页面横向溢出。
- 弹窗支持 Escape 关闭、键盘焦点约束与关闭后焦点恢复；按钮、输入框均有可读标签，空态与校验提示明确。

## 未来服务接入

真实环境需提供账号鉴权/连接状态、按账号隔离的联系人与会话接口、附件上传下载、消息发送及异步送达回执、实时接收、群组创建与成员同步、持久化及权限校验。企业号可用能力需按实际选用服务及账号权限确认；前端演示不承诺特定 WhatsApp API 可支持全部功能。

## 验收清单

- 三渠道位于整个工作区上方，邮件与两个 WhatsApp 渠道内容互不混合。
- 两个 WhatsApp 渠道均有可切换的多个示例账号，未读统计正确，草稿与附件隔离。
- 单聊/群聊可发送文本、图片、视频、文件，预览/播放/下载有效；超限与非法输入有提示。
- 联系人搜索支持姓名、公司、号码；空结果正确；已有会话不重复。
- 群名或成员不合要求不能创建；成功后可查看群成员并继续聊天。
- 手机（390px）、平板（820px）、桌面（1440px）检查布局、浏览器控制台及静态资源加载。
- 修改仅落入项目源码，不直接修改预览镜像或部署线上。

回归脚本：`scripts/test-inquiry.cjs`。从项目根目录运行 `python3 -m http.server 8765 --bind 127.0.0.1`，再运行 `node scripts/test-inquiry.cjs`。脚本需要 Playwright 与 Chrome；可用 `PLAYWRIGHT_MODULE` 指定现有 Playwright 包路径，`INQUIRY_BASE_URL` 指定预览地址，`INQUIRY_BROWSER_CHANNEL` 指定浏览器渠道。测试截图输出到 `/tmp/inquiry-*.png`。

真实 WhatsApp 接入、持久化和线上部署不属于本次前端实施结果。

## 独立 Demo 导出

运行 `npm run build:inquiry`，生成 `dist/inquiry-demo.html`。只需分享这一个 HTML 文件，即可在浏览器中直接打开；样式、脚本、图标和示例数据均已内嵌。导出文件由源码自动生成，后续修改仍在项目根目录进行，不手工维护第二套代码。

独立文件已在 Chrome 断网状态下通过全部 13 组交互与多尺寸检查。测试可设置 `INQUIRY_OFFLINE=1`，并将 `INQUIRY_BASE_URL` 指向导出文件的 `file://` 地址。消息和群组仍为当前页面内演示，刷新恢复示例数据。
