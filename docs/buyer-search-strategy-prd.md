# 买家搜索策略 PRD

## 1. 文档信息

- 产品：OntoZ 工作台
- 所属模块：企业本体
- 页面：买家搜索策略
- 版本：V1.0
- 页面路由：`#ontology/buyer-search-strategy`

## 2. 产品目标

买家搜索策略将企业对目标客户的判断规则组织为可解释、可追溯的图谱，帮助用户理解 Zoe 如何从买家画像逐层推导搜索词、业务范围和产业链身份，并明确哪些对象需要排除。

页面需要回答：

1. 企业当前重点寻找哪些买家？
2. 每类买家对应哪些搜索关键词？
3. 买家应该经营哪些产品或业务，哪些业务需要排除？
4. 买家应该处于产业链中的什么位置，哪些身份需要排除？

## 3. 图谱层级

### 第一层：买家画像

描述目标买家的业务场景、核心需求与企业特征。本期包含：

- 工业制造企业
- 仓储物流运营商
- 设施管理服务商

### 第二层：买家搜索关键词

为每个买家画像配置可用于搜索引擎、企业数据库和行业名录的关键词组合。关键词优先使用买家常用的英文行业表达，避免直接使用供应商自我描述。

### 第三层：主营产品 / 业务

分为两种关系：

- 应包含：目标买家应经营或具备的产品、服务及应用能力。
- 需排除：容易造成误匹配，但不属于目标客户的产品或业务。

### 第四层：产业链身份

分为两种关系：

- 应包含：目标买家在产业链中的有效采购、使用或集成身份。
- 需排除：缺少真实应用场景或采购决策能力的身份。

## 4. 页面结构

1. 返回与面包屑
2. 页面标题、版本和更新时间
3. 四层图谱规模摘要
4. 图谱关系筛选
   - 全部关系
   - 只看包含
   - 只看排除
5. 当前聚焦节点说明
6. 四列横向图谱
   - 每个买家画像形成一条横向泳道
   - 节点间使用连接线表示推导关系
   - 包含关系使用蓝绿色
   - 排除关系使用红色

## 5. 核心交互

- 点击企业本体的“买家搜索策略”进入本页。
- 点击“返回企业本体”回到 `#ontology`。
- 点击图谱节点后：
  - 当前节点显示选中态。
  - 上方聚焦说明同步更新节点名称、层级和作用。
  - `aria-pressed` 同步更新，支持键盘操作。
- 关系筛选：
  - 全部关系：恢复所有节点。
  - 只看包含：突出应包含关系，弱化排除关系。
  - 只看排除：突出排除关系，弱化包含关系。
- 手机和平板端图谱保持四层结构，通过横向滑动浏览，不改成容易丢失关系的一列列表。

## 6. 演示数据

### 工业制造企业

- 关键词：humanoid robot manufacturing、flexible automation、robotic visual inspection
- 应包含业务：工业自动化集成、生产线柔性改造、机器视觉质检
- 排除业务：家用服务机器人、纯软件 RPA
- 应包含身份：终端制造商、自动化方案集成商、工厂工程承包商
- 排除身份：机器人零部件贸易商、培训 / 媒体机构

### 仓储物流运营商

- 关键词：warehouse humanoid robot、intralogistics automation、case picking robot
- 应包含业务：仓储运营、电商履约、内部物流自动化
- 排除业务：快递末端配送、家庭搬运
- 应包含身份：仓库运营方、第三方物流企业、电商履约中心
- 排除身份：物流设备零售商、货代经纪

### 设施管理服务商

- 关键词：facility inspection robot、autonomous inspection、predictive maintenance
- 应包含业务：设施巡检、资产运维、工业园区管理
- 排除业务：消费级安防摄像头、清洁家政
- 应包含身份：设施管理公司、公用事业运营商、工业园区业主
- 排除身份：物业中介、设备耗材供应商

## 7. 响应式与可访问性

- 桌面端优先在一个视口内展示完整四层关系。
- 图谱最小宽度固定，空间不足时在图谱区域内部横向滚动。
- 图谱区域提供明确的滑动提示。
- 所有可选节点和筛选项使用原生按钮。
- 图谱节点具有可见焦点样式和 `aria-pressed` 状态。
- 颜色不作为唯一语义，同时显示“应包含”“需排除”文字。

## 8. 验收标准

- `#ontology/buyer-search-strategy` 可直接访问和刷新。
- 侧边栏“企业本体”保持选中。
- 四个层级标题、三条买家泳道和包含 / 排除节点完整显示。
- 三个关系筛选可切换且状态正确。
- 任一图谱节点可聚焦，并更新节点说明。
- 返回入口正常。
- 390px、768px、1440px 无页面级横向溢出；小屏仅图谱画布内部横向滚动。
- 控制台无 JavaScript 错误。
