# Lucas 浏览器建站 Demo

2026-10-01：默认建站流程已迁移至浏览器。访问托管网页即可使用，无需 Python 服务。保存、模拟生成、静态预览、演示发布、版本恢复、询盘和示例竞对分析均不请求 Lucas API。数据保存在当前网站的浏览器本地存储；不会自动读取旧 SQLite，不跨设备共享，清除网站数据会重置。

预览入口为 `lucas-site.html?preview=1`，发布入口为 `lucas-site.html`，均相对于当前部署目录。关闭页面不运行任务，重新打开按时间戳恢复模拟进度。

以下是此前本地服务版本的历史实现记录，其启动要求、SQLite、真实竞对抓取和后台任务说明不适用于当前默认浏览器版。

# Lucas 本地建站 Demo

依据 [Lucas 建站 PRD](https://iihcw7mp26x.feishu.cn/docx/Ib6qd1DR4opYUKxxptQcD3uanKX) 实现，PRD 已通过飞书 CLI 读取。正式源码直接维护在本项目中，没有单独的 Site 镜像或第二套页面源码。

## 运行

在项目根目录执行：

```bash
npm run demo:lucas
# 不使用 npm 时：
python3 scripts/lucas-demo-server.py --port 8766
```

打开 <http://127.0.0.1:8766/#lucas>。要求 Python 3，无第三方 Python 依赖。服务只监听本机地址，使用本地演示账号，无生产登录鉴权。

SQLite 数据保存在 `.lucas-demo/`，重启服务保留配置、任务进度、询盘和发布版本。浏览器关闭后，只要服务仍在运行，生成任务会继续执行；服务重启后会继续处理持久化任务。需要独立演示数据时，为服务指定新的 `--data-dir` 和空闲 `--port`，无需删除现有记录。

## 演示流程

1. 从案例开始，筛选行业与网站类型，预览并选择案例。
2. 调整主题色、字体、首屏和页面模块，查看桌面及手机预览。
3. 在「风格与结构」点击「生成网站」，自动带入企业本体与建站资料，不再显示本体信息或 brief 确认步骤。原 `#lucas/profile` 与 `#lucas/review` 地址返回风格与结构。
4. 显示旋转 loading、进度条与逐阶段进度：读取企业本体 → 查看产品结构 → 理解建站目标 → 编排网站内容 → 适配与检查。文案引用任务快照中的企业、产品、目标客户、市场、页面和 CTA，标注为模拟进度；刷新或离开后继续同一任务。失败显示重试入口，完成/失败停止动画；减少动态效果时保持静态进度。
5. 点击「预览并发布网站」进入网站确认页，逐页核对企业本体内容，可切换桌面/手机或返回修改。
6. 确认页左下角返回修改，右下角「在线预览」仅打开草稿；主按钮「发布网站」进入上线设置，填写域名、询盘接收邮箱与语言。检查问题在上线设置页展示；无需提交测试询盘即可发布。
7. 上线设置保存后点击「发布网站」，创建发布快照并进入 Lucas 日常首页。域名、询盘接收邮箱和语言可在网站设置查看；恢复历史版本只改变草稿，需重新发布才影响当前网站。

主要入口：

| 地址 | 用途 |
| --- | --- |
| `/#lucas` | 首次进入建站向导；生成完成后默认进入日常首页 |
| `/#lucas/editor` | 草稿编辑器 |
| `/#lucas/confirm` | 企业网站内容预览与确认 |
| `/#lucas/launch` | 域名、询盘接收邮箱与语言设置 |
| `/#lucas/leads` | 询盘管理 |
| `/#lucas/settings` | 域名设置和发布版本 |
| `/lucas-preview` | 草稿预览，不可提交询盘 |
| `/lucas-site` | 最近一次成功发布的网站 |

### 单模板建站

- 从模板列表选择一个网站模板，按钮为“使用此模板并继续”。配色与字体可分别选择「沿用模板」或「AI 调配」，默认沿用模板，不支持跨案例拼接。AI 调配在当前本地 Demo 中按企业行业匹配预设风格，选择结果会写入草稿并用于实时预览；没有调用生产 AI 服务。

- 同一区域提供首页预设模块的添加、删除和排序；首屏固定保留，不提供自定义模块、复制、隐藏/显示。已存在的模块不重复添加，删除后可从预设列表重新添加；支持自动保存和刷新后恢复。
- 移除第 1 步「当前网站模板 / 更换模板」整块及预览底部的模块编辑提示。
- 关闭模板预览不会保存风格选择。使用新的模板时恢复该模板的完整页面结构，保留企业本体资料及已发布网站。
- 模板弹窗关闭按钮放在右上角，复用 Figma Dialog 3801:135 与既有按钮组件。

### 重新演示建站

- Lucas 首页顶部提供“重新从零建站”，点击后返回建站起点，清空草稿、案例参考、页面配置和撤销记录，并停止当前生成任务。刷新后仍保持新的建站状态。
- 已发布网站、发布历史、询盘及网站设置保留；再次完成建站并发布后才替换已发布网站。企业资料仍从 Mock 企业本体自动获得。

### 本地数据与外部服务

- 企业本体适配器是 `js/ontology.js` 中的 `getEnterpriseOntologySnapshot()`。当前返回完整的 NOX Mock 快照，不依赖页面 DOM 或生产企业本体 API。包含目标市场、企业、产品参数、示例联系方式、现有宣传素材和虚构认证条目，均标记为演示数据；Mock 认证不会作为真实资质发布。点击生成网站时会自动载入 Mock 资料，保留设计和已编辑页面。
- 配置保存、异步任务状态、询盘提交与去重、阅读状态、处理状态、备注、通知和版本快照由本地 SQLite 服务实际保存。历史测试询盘不计入经营指标；现已移除测试入口，草稿预览不可提交询盘。
- AI 文案和页面生成使用确定性的本地模拟；展示用经营指标和优化建议有演示标记，不代表真实访客分析。仅提供有限时间范围和示例建议操作，未接入分析平台或生产 AI。
- 发布是本地版本切换，不会上传公网。域名设置仅演示格式校验与保存，不执行 DNS 或证书配置。可模拟发布失败，失败不会覆盖当前已发布版本。
- 网站包含首页、产品列表、单个本体产品详情、关于和联系页。编辑器提供首页模块结构配置及各页文案编辑，不包含生产级多产品 CMS、多人权限或真实邮件发送。
- 页面以结构化内容渲染，正文按文本转义，主题和图片路径有校验。该服务面向本机演示，不应直接作为公网生产服务部署。
