# 搜索词验证 PRD

## 1. 文档信息

- 产品：OntoZ 工作台
- 所属模块：企业本体 / 买家搜索策略
- 页面：搜索词验证
- 版本：V1.0
- 页面路由：`#ontology/buyer-search-strategy/keyword-validation`
- 设计参考：工作台 Figma `16:499` 下的搜索词验证页面

## 2. 产品目标

搜索词验证用于在正式配置买家画像前，以小批量结果快速验证搜索词质量。用户每次试搜一个关键词并查看 20 家企业，结合人工判断或 Zoe 自动判断，确认关键词是否能稳定找到目标客户，再将满意的搜索词配置到具体买家画像。

页面需要帮助用户回答：

1. 这个搜索词能否找到目标类型的企业？
2. 搜索结果中有多少待判断、已入池或已过滤企业？
3. 待判断企业应由人工判定，还是交给 Zoe 批量判断？
4. 这个搜索词是否值得加入买家画像？

## 3. 页面入口与结构

### 3.1 页面入口

- 在“买家搜索策略”页头新增按钮“搜索词验证”。
- 点击后进入独立页面 `#ontology/buyer-search-strategy/keyword-validation`。
- 搜索词验证页提供返回“买家搜索策略”的面包屑。

### 3.2 页面结构

1. 面包屑：企业本体 / 买家搜索策略 / 搜索词验证
2. 搜索卡片
   - 标题与功能说明
   - 搜索词输入框
   - “开始搜索”按钮
   - 结果返回后显示“配置搜索词至画像”
3. Zoe 判断提示
   - 仅在结果中存在“待判定”企业时显示
   - “确认交给 Zoe”触发批量判断
4. 搜索结果列表
   - 公司名称
   - 公司官网
   - 国家地区
   - 公司地址
   - 公司类型
   - 结果类型
   - 客户池状态或过滤原因
   - 待判定企业的人工赞 / 踩操作
5. 初始态、无结果态
6. 重复搜索确认弹窗
7. 配置搜索词至画像弹窗

## 4. 搜索规则

- 搜索词必填，去除首尾空格后才允许搜索。
- 点击“开始搜索”或在输入框按 Enter 均可触发搜索。
- 每次有结果的搜索固定返回 20 条企业结果。
- 搜索中的按钮显示加载状态，完成后恢复。
- 结果按搜索词生成一批独立验证结果，不直接改动正式画像。

## 5. 结果类型与状态

### 5.1 待判定

表示企业尚未完成匹配判断。

- 显示琥珀色“待判定”标签。
- 提供“符合”与“不符合”两个按钮。
- 点击“符合”后：
  - 结果类型更新为“已入池”。
  - 客户池状态更新为“人工准入”。
- 点击“不符合”后：
  - 结果类型更新为“已过滤”。
  - 过滤原因更新为“人工判定不匹配”。
- 可通过 Zoe 提示卡将当前全部待判定结果批量交给 Zoe。

### 5.2 已入池

表示企业已存在于全量客户池。显示绿色“已入池”标签，并显示以下任一客户池状态：

- Zoe 准入
- 人工准入
- 国家不匹配
- 产品不匹配
- 身份不匹配

“已入池”与“匹配”不是同义关系：后三种不匹配状态说明企业已经存在于全量客户池，但不符合当前画像条件。

### 5.3 已过滤

表示企业已被系统规则排除。

- 显示灰色“已过滤”标签。
- 同时显示明确过滤原因，如“公司主体重复”“非目标行业”“缺少有效官网”等。

## 6. Zoe 自动判断

- 搜索完成后，如果结果中存在“待判定”企业，展示提示“让 Zoe 自动判断客户信息”。
- 点击“确认交给 Zoe”后：
  - 将当前所有待判定企业批量转换为“已入池 / Zoe 准入”或“已过滤 / 具体原因”。
  - 更新列表状态与结果统计。
  - Zoe 提示卡在没有待判定结果后隐藏。
  - 通过轻提示反馈完成数量。
- 已由人工判断的企业不被 Zoe 覆盖。

## 7. 配置搜索词至画像

- 搜索返回至少 1 条结果后，显示“配置搜索词至画像”。
- 点击后打开弹窗，标题中展示当前搜索词。
- 弹窗内选择目标画像，本期可选：
  - 工业制造企业
  - 仓储物流运营商
  - 设施管理服务商
- 确认后关闭弹窗，并提示“已配置至所选画像”。
- 未选择画像时不可提交。

## 8. 特殊状态

### 8.1 搜索词已在画像中

- 当搜索词已经配置到任一画像时，在正式搜索前展示确认弹窗。
- 弹窗需要说明该词当前所在画像，以及继续搜索会生成一批新线索。
- 用户可取消或确认继续搜索。
- 取消后保留输入内容，不刷新当前结果。

### 8.2 无搜索结果

- 搜索结果为空时展示独立空状态。
- 提示“没有找到相关企业”。
- 引导用户缩短搜索词，或改用行业、产品及应用场景表达。
- 不展示 Zoe 判断提示和“配置搜索词至画像”入口。

### 8.3 初始状态

- 尚未搜索时展示功能引导。
- 明确说明“每次返回 20 家企业，先验证再配置画像”。

### 8.4 Mock 验证数据

- “重复搜索词”快捷入口使用 `Solar energy`，触发已配置在“欧洲新能源采购商”画像中的确认弹窗。
- “空结果”快捷入口使用 `no-results`，触发无搜索结果状态。
- Mock 入口仅用于原型验证，不影响用户输入其他关键词的正常搜索。

## 9. 响应式与可访问性

- 1440px 桌面端按设计稿展示横向字段列表。
- 768px 平板端压缩次要字段，保持操作可见。
- 390px 手机端将每条结果转换为信息卡，不产生页面级横向滚动。
- 所有操作使用原生按钮、链接、输入框或选择框。
- 弹窗使用 `role="dialog"`、`aria-modal="true"` 并支持 Escape 关闭。
- 搜索结果区域使用 `aria-live` 报告状态变化。
- 图标不作为唯一语义，状态同时展示文字。

## 10. 验收标准

- 买家搜索策略页存在“搜索词验证”入口，点击后路由正确。
- 搜索非空关键词后固定返回 20 条结果。
- 三类结果均有明确视觉标签和补充说明。
- 待判定企业可以逐条赞 / 踩，并正确更新类型和状态。
- “确认交给 Zoe”可批量完成剩余待判定结果，且不覆盖人工判断。
- 五种客户池状态均能在演示结果中查看。
- 已过滤结果显示具体过滤原因。
- 搜索词可以配置到指定画像。
- 已在画像中的搜索词会在搜索前二次确认。
- 无结果时展示优化关键词提示。
- 390px、768px、1440px 无页面级横向溢出。
- 控制台无 JavaScript 错误，图片、字体与图标正常加载。
